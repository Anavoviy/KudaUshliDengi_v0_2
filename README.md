## Основная идея
Позволит записывать расходы и доходы, ставить финансовые цели и формировать здоровое отношение к деньгам через систему геймификации.

## Ключевые моменты
- Отсутствие регистрации
- Привязка только к аккаунту Telegram
- Простые текстовые команды
- Автокоррекция ввода
 
## Возможности
### Учет операций
- Простой ввод
- Расходы с детализацией
- Исправление ввода категорий
- Отмена и редактирование последних операций

### Система целей (копилок)
- Создание целей накоплений
- Визуальное отслеживание прогресса
- Пополнение и снятие средств
- Уведомления о достижении целей

### Умные категории
- 2-уровневая иерархическая структура
- Нечёткий поиск с автокоррекцией
- Управление через отдельное меню

### Геймификация
- Достижения и бейджики
- Визуализация прогресса
- Образовательные квесты и челленджи *(скоро)*

## Быстрый старт
Начни с простого:
```text
150 такси - создай простой расход
+50000 зарплата - создай доход
5000 продукты: 1000 хоз, 650 вкусняшки - создай сложный расход
```
